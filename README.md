# AozoraReader

青空文庫の作品を縦書きで快適に読むためのAndroidアプリです。

## 特徴

- **本格的な縦書き表示**: WebViewを使用せず、カスタム描画エンジンによる高速で美しい縦書き表示を実現。
- **ルビ（ふりがな）対応**: 青空文庫特有のルビ記法を解析し、適切に配置します。
- **直感的な操作**:
    - 左右タップまたはスワイプによるページめくり（右開き）。
    - 画面下部のスライダーによる高速なページ移動。
- **作品管理**:
    - 青空文庫の全作品リストから検索・ダウンロードが可能。
    - 最近読んだ順に自動で並び替え。
    - ダウンロード済みデータのファイルサイズ表示。
- **カスタマイズ**:
    - フォントサイズの変更（小さめ・ふつう・大きめ）。
    - ダークモード対応。
- **自動整形**: 日本語の慣習に合わせた段落先頭の自動一字下げ機能。

## 使用フォントについて

本アプリでは、縦書きの視認性を高めるために以下のフォントを同梱・使用しています。

- **IPA明朝 (IPA Mincho)**
    - 開発者: 一般社団法人文字情報技術促進機構 (IPA)
    - ライセンス: [IPAフォントライセンスv1.0](https://fonts.jp/ipa_font_license_v1.html)に基づき使用しています。

## 開発環境

- Kotlin
- Android Jetpack (Room, ViewPager2, Coroutines, Lifecycle)
- OkHttp3 (ネットワーク通信)
